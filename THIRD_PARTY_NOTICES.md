No runtime downloads or subscriptions are used. Original project code,
meshes (including Blender sources), UI, icon, and synthesized audio use the repository MIT license.

| Component | Version / source | License | Use and obligations |

Godot's copyright inventory comes from the exact engine release. It records
bundled libraries and notices; not every listed library is active in the Web
runtime. In-game credits also link Godot's official license page.

Scientific sources are references, not shipped photographs, videos, models,
database dumps, or copied descriptions. Journal text is original paraphrase.
NOAA and MBARI have not endorsed or reviewed this game.

The Poly Haven material is a bare-rock visual reference, not photographic data
from a hydrothermal vent. The material is artistically repurposed. The Web
package includes its provenance and CC0 notice.

For future assets, record the exact source/version, author, license, attribution,
commercial rights, and whether source files can be redistributed publicly. A
license permitting a compiled commercial game may restrict source distribution.

Development automation uses official GitHub actions and Python's standard library.
Playwright is optional browser-test tooling, not a runtime dependency.
